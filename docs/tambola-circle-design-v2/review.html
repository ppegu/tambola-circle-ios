The round keeps moving

Ready time: 02:00. Claim and proof reviews: 02:00 each. The host can configure these per table.

Unanswered reviews approve at expiry. Disagreement goes to the host. If no final decision arrives in time, the round ends without a winner.

Co-host takeover and rejoining keep the original deadlines.

Device sign-in: supported SIM selection only; no typed number or recovery code. A selected SIM number is not server-verified ownership. Unsupported devices keep the offline option. Read the platform feasibility and remaining sign-in limits.

Implementation baseline

Every device talks to the authoritative table server. Game history, markings, calls, reviews and role changes are recorded; returning players restore the same table and round state.

Miss the ready deadline and you watch that round. Full house is declared for one 15-number panel. Public tables remain “Coming soon.”

Concept-image and platform notes

These are generated design images, not screenshots of implemented software. The written specification governs exact ticket data, participant counts, text, permissions and transitions. Screens depict different example states, rather than one continuous match. Individual views use CSS crops of the unchanged image boards.

Android immersive mode allows transient system-bar reveals. SIM support requires a real native-device spike; no universal Android/iOS SIM-number verification capability is claimed. Gallery files and JavaScript were statically checked; browser interaction testing was unavailable because local-file access was blocked by browser policy.
